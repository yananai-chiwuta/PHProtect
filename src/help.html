Using PHProtect

PHProtect adds local warning signals and a moment to review sensitive actions. Checks run on your device. You can inspect every script in the source.

A browser extension cannot fix a vulnerable PHP server.

PHP2Shell is a server-side threat. PHProtect compares advertised versions with a bundled advisory and adds best-effort website guards. It cannot verify that a server is patched, detect every attack, or certify a site as safe.

Start in three steps

  1. Pin PHProtect

    Use your browser's extensions menu to keep the status button nearby.

  2. Reload your open websites

    Newly installed content scripts need a fresh page load. The popup reports whether guards have loaded.

  3. Check the evidence

    Open the popup for PHP hints, page signals and settings. Refresh headers only when you want an extra request to that page.

Understand PHP hints

An old version may need attention. A version meeting the PHP2Shell cutoff is only a header claim. Hidden versions and unverified branches stay unknown. Vendors can backport fixes without changing that claim.

Review sensitive actions

Supported Ethereum requests can open an extension decision window. English recovery phrases and recognized clipboard commands can trigger warnings. Read the hostname, frame and wallet details before continuing.

Know the limits

  • Page scripts can interfere with page-world wallet and clipboard hooks. Providers injected late or hidden outside supported APIs may bypass them.
  • A site may observe keystrokes or input before phrase detection. Clearing text cannot recall data already sent. Non-English phrases and custom editors may be missed.
  • Page signals are heuristics, including legitimate cross-site forms and embedded content. False positives and missed attacks are expected.
  • Browser pages, extension stores and some protected documents restrict extensions. Incognito and file URLs are not supported by default.
  • PHProtect does not simulate transactions, scan downloads, block network traffic or remove malware. An extension-owned window can still be visually imitated by a website.

Your controls

The popup's protection switches apply globally. Site exceptions use the exact hostname, across schemes and ports; subdomains have separate settings. Skipping medium wallet warnings never skips high-risk prompts. Pausing the wallet guard leaves other enabled checks running.

Privacy, in plain language

Checks run on your device. PHP headers, some page text and form values, supported wallet requests and intercepted clipboard text are processed locally. Seed words and clipboard text are not sent to the background or written to extension storage. Short findings, hostnames and a small tab activity list stay in browser session storage; preferences and site exceptions stay locally until reset or uninstall.

Refreshing headers sends HEAD to the current page URL, with GET only if HEAD is unsupported. Cookies are omitted. The website still receives your IP address, URL and normal request metadata. Copying a report puts its hostname and findings on your clipboard.
