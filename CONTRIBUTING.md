# Project policy

PHProtect does not accept pull requests, including documentation or dependency updates. Pull requests are closed without code review by the included workflow when GitHub Actions is enabled.

You are welcome to fork the project, change it and distribute your fork under the applicable MIT and third-party license terms. Use your own release identity so users can distinguish your version.

Non-sensitive bug reports are welcome as issues. Include the browser and extension version, expected behavior and a minimal reproduction using inert data. Remove private URLs, wallet payloads, account information and all real secrets. Maintainer responses and fixes are not guaranteed.

For sensitive vulnerabilities, see SECURITY.md. Do not submit exploit details through a pull request.
